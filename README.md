# Englify v0.6 — JavaFX desktop app

**Englify** — навчання англійських слів на Windows. Java 21 · JavaFX 21 · SQLite · Maven. Програма зберігає дані локально у `C:\Users\<користувач>\.englify\englify.db`.

## Запуск у IntelliJ IDEA

1. Розпакуйте `Englify-Java-v0.6.zip` та відкрийте **папку `Englify`**, у якій лежить `pom.xml` (`File → Open`).
2. Оберіть Project SDK **JDK 21** та дочекайтеся імпорту Maven.
3. Відкрийте `src/main/java/com/englify/Launcher.java` і натисніть зелену стрілку біля `main()`.
4. Якщо виникне **JavaFX runtime components are missing**, запустіть у правому вікні Maven → Plugins → **javafx → javafx:run**.

Коли Maven встановлено у PATH, у корені є `run-windows.bat` (подвійне натискання) або команда `mvn clean javafx:run`. Звичайний користувацький `.exe` ще не запаковано: це проєкт для IntelliJ та Maven.

## Як тепер працює

### Головна
- Кільце щоденної цілі малюється JavaFX-фігурами, **не** вбудованим ProgressIndicator, який раніше накладав галочку на `15/15`.
- «Почати повторення» запускає тільки слова, **термін яких настав**; «Нові слова» — ще не переглянуті картки.
- «Слово дня» вибирається серед слів поточного рівня, для яких є приклад **англійською і українською**.
- Шлях рівнів A1–A2–B1 з відміткою поточного рівня; перемикач світлої/темної теми у верхньому правому куті.

### Картки та тестування
- **Не повноекранні:** обидва розділи відкриваються в основній області із видимим боковим меню.
- Карточка: слово, IPA за наявності, системне озвучування Windows; на звороті — переклад і доступний приклад використання; анімація перегортання.
- **«Знаю»** та **«Ще вчу»** можна натиснути і без перегортання; працює мишка та клавіші `←`/`→`. `Space` — перегорнути.
- Після сесії з картками тест формується зі **щойно опрацьованих** слів. Також тест можна запустити окремо — він використовує лише слова з історії карток.
- Тест: 4 варіанти (`1`–`4`), ✓/✕, підказка в разі помилки, показ правильної відповіді, Enter — далі. Можна обрати `EN → UA`, `UA → EN`, `Змішано`.

### Словник
**Тільки слова, з якими користувач уже працював**, із пошуком, двопанельним переглядом і чотирма вкладками:
- **Усі** — усі слова, побачені/оцінені через картки;
- **Нові** — ті, що **вперше** зустрілися саме сьогодні;
- **Вивчаю** — ще не підтверджені останнім правильним тестом;
- **Опановані** — слова, для яких остання тестова відповідь правильна. Якщо пізніше помилитися, вони знову перейдуть у «Вивчаю».

### Прогрес і налаштування
- Зростання засвоєних слів, точність поточного рівня, час навчання, річна карта реальної активності та статус.
- Світла, темна й системна теми; три розміри шрифту; денна ціль, кількість слів і тривалість сесії; експорт особистих слів до CSV.
- Налаштування зберігаються між запусками. База v0.5 не очищується і не мігрує примусово.

## Дві важливі межі цієї збірки

**1. Наповнення A1/A2 усе ще недостатнє:** A1 — 254, A2 — 240, B1/B1+ — 2 628 записів. Запит на **по 1 000 перевірених слів A1 та A2** не завершено. Неперевірені переклади та випадковий поділ за CEFR не додаються лише заради лічильника. CEFR-J (Tono Laboratory, TUFS) можна використати як опору для рівнів, але до готової картки ще потрібні якісні українські переклади та перевірка багатозначності. Див. `docs/SOURCES.md`.

**2. Контекстні речення покривають не всю базу:** у `examples.tsv` наразі **263 пари EN/UK речень** (240 нових у v0.6); для слів без перевіреного речення на звороті картки показується нейтральна інформація про відсутність прикладу. Слово дня обирається лише із записів із прикладом. Автоматично вигадані речення не видаються за перевірені.

## Структура коду

```
com/englify/Launcher.java             — точка входу, звичайний main()
com/englify/EnglifyApp.java           — JavaFX екрани, навігація, реакції
com/englify/data/Database.java        — SQLite, словник, історія, приклади
com/englify/learning/SrsScheduler.java — інтервальні повторення
com/englify/ui/AppSettings.java       — локальні налаштування
com/englify/ui/ThemeManager.java      — тема Windows/вікна
src/main/resources/com/englify/*      — CSS, TSV слова, IPA, речення
```

## Перевірки / обмеження середовища

Під час підготовки v0.6 виконано: синтаксичний розбір **11 Java-файлів** компілятором JDK 21, компіляцію Java-моделей/SQL-репозиторію/алгоритму повторення, перевірку TSV та SQL-сценаріїв у SQLite. **Повний запуск JavaFX не був доступний** у середовищі збірки через відсутність Maven та JavaFX runtime. Це не означає, що GUI випробуваний на Windows. Див. `docs/QA_v0.6.md`.
