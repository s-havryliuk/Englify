# Englify — наступні ітерації

## v0.3 — реалізовано у вихідному коді

- Єдина палітра, два оформлення + системний вибір, іконки та цілісний логотип.
- Виправлена особиста колекція збережених слів, імпорт із коротким promptText, 50 рядків на сторінку.
- Спрощений алгоритм інтервальних повторень із таблицею `review_state`.
- Кнопки самооцінки на картках, помилки й підсумок сесії, хоткеї.
- Підказки типу word/phrase, 23 приклади з транскрипціями, 435 нових слів A1/A2.
- Понеділок як початок тижня, виправлені відмінки числівників.

## v0.4 — якість вмісту та вправ

- Перевірений і ліцензійно чистий словник A1/A2/B1, ручна перевірка перекладів/частин мови, індексація за семантичними темами.
- Контекстні дистрактори за POS та значенням; позначення неправильних відповідей у режимі практика.
- Вправи на введення, перевірка опечаток (Levenshtein), з'єднання пар і пропуски.
- Сприйняття словоформ (повторювані слова), CSV та Anki-імпорт/експорт.

## v0.5 — якісний desktop-реліз

- Приклади та перевірена IPA для більшості слів, кешована офлайн-озвучка.
- Міграції БД з тестами; належна доменна архітектура: Repository + Service + JavaFX views.
- Теплова карта, прогрес за навчальними темами та початкове визначення рівня.
- `jpackage` з Java runtime; код перевірено на реальному Windows ПК, README зі скриншотами.

## Після MVP — збережені ідеї

- «Текст у колоду»: вставити текст, визначити незнайому лексику, створити власні картки.
- AI-аналіз документів та фотографій. Без прихованих або удаваних AI-функцій у поточному UI.
