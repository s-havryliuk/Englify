# Englify v0.4 — що зроблено та що лишилось

ЗРОБЛЕНО: меню; тематичний вибір на огляді для A1/A2; місячний календар; прогрес поточного рівня; лише переглянуті слова в словнику; тест лише на переглянутих словах; позначення ✓/✕ та правильного варіанта; повідомлення під словом; світла, темна, системна теми; три розміри шрифту; українські чернеткові підказки вимови; TTS Windows; зміни кольорів; прибрано дублюючий вибір рівня у верхньому куті.

НЕ ГОТОВО: 1000 перевірених A1 та 1000 перевірених A2; фонетична верифікація всіх підказок; IPA, приклади речень і частини мови для всіх карток; справжній тематичний поділ на B1; пакетний AI-аналіз фото й тексту; інсталятор `.exe`; GUI-тест на Windows.

При роботі з вимовою автоматична передача фонем CMU українськими літерами — лише початковий матеріал для редактора. На екрані для користувача немає слова «приблизна», як було узгоджено, але в документації якість описано чесно.
