# Englify v0.4 — Windows перевірка

1. Відкрити `Launcher.main()`; за проблеми runtime запустити Maven `javafx:run`.
2. Перевірити порядок бокового меню: Огляд, Картки, Тестування, Словник, Мої слова, Статистика, Налаштування.
3. В Огляді обрати A1, тему, почати 5 карток.
4. Перегорнути 2–3 картки; перевірити вимову (підказка може бути відсутня, якщо ще не перевірена), кнопки «Знаю», «Ще вчу», анімацію.
5. Перейти в Словник: тільки реально перегорнуті слова; пошук EN/UK.
6. У Тестуванні перевірити, що пропонуються лише знайомі картки; ✓/✕ на кнопках, правильний варіант та текст під словом; клавіші 1–4, Enter.
7. У Статистиці — один вибраний рівень, місячний календар з активним сьогодні, інші місяці через меню.
8. У Налаштуваннях — системна, світла, темна тема; малі, середні й великі шрифти; перевірити, що контент тесту вміщується у вікно.
9. Перезапустити програму: прогрес, словник, тема та розмір шрифту мають залишитися.
10. Натиснути «🔊 Слухати» у Windows: має використовуватись системний голос, якщо він доступний.
11. Перевірити збереження власних слів окремо від прогресу інших карток.
