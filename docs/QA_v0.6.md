# QA v0.6 — стан перевірок

## Виконано в середовищі створення

- [x] Синтаксичний розбір усіх 11 Java-класів JDK 21: без синтаксичних помилок.
- [x] Компіляція моделей, Database, SrsScheduler, UkrainianForms без JavaFX-залежностей.
- [x] `words.tsv`: 3 122 записи, 0 точних повторів за (англійське слово, переклад, рівень).
- [x] `examples.tsv`: 263 пар речень із наявними словниковими картками; 114 A1, 71 A2, 78 B1.
- [x] SQL-перевірки: «Нові» = перший перегляд сьогодні; «Опановані» = останній успішний тест (якщо наступний тест помилковий, стан повертається).
- [x] Головна: прогрес-кільце більше не залежить від стандартного ProgressIndicator.
- [x] Картки й тести: розміщуються в тому самому BorderPane із сайдбаром.
- [x] Стара база SQLite не видаляється; приклади додаються за схемою INSERT/UPDATE.

## Потрібна перевірка в IntelliJ IDEA на Windows

- [ ] Реальна компіляція JavaFX UI через Maven та старт Launcher.
- [ ] Візуальне компонування на 1090×720, 1280×800, 1536×960 (кольори, обрізання, тіні, кільце).
- [ ] Керування мишкою/Space/1–4/Enter у різних станах карток і тесту.
- [ ] «Головна → Почати повторення» лише due; «Нові слова» лише unseen.
- [ ] Вкладки «Усі / Нові / Вивчаю / Опановані» на реальній історії після тестування.
- [ ] Кольори світлої теми, швидкі іконки перемикання, перевірка системної теми Windows.
- [ ] Озвучення англійським голосом Windows (залежить від установленого TTS).
- [ ] Експорт CSV і відкриття в Excel (UTF-8 із BOM).
- [ ] Старі особисті дані не втрачаються після оновлення.
