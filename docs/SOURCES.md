# Джерела та ліцензії

- `words.tsv`: стартовий словник і навчальний лексичний мінімум B1+ з PDF користувача: Одарчук Н. А., Гордієнко Ю. А., Василенко О. В. *Лексичний мінімум з англійської мови (рівень B1+)*. Луцьк, 2023. Це не офіційна CEFR-база.
- `examples.tsv`: 263 короткі пари власних прикладів речень англійською та українською. Деякі речення згенеровані/складені спеціально для проєкту, без незалежної редакторської вичитки. Не варто називати їх офіційним корпусом.
- `pronunciation_ipa.tsv`: широкий IPA, отриманий з фонем американської англійської CMU Pronouncing Dictionary; фонетична розмітка частково автоматична, не суцільна професійна вичитка. Ліцензія — `CMUDICT_LICENSE.txt`.
- Орієнтир для майбутньої перевірки лексики: *The CEFR-J Wordlist Version 1.6*, compiled by Yukio Tono, Tokyo University of Foreign Studies: https://cefr-j.org/download_eng . Джерело має вимоги до атрибуції; не додано його неперевірені українські переклади в застосунок.

Перед публічним релізом або перенесенням усіх матеріалів у відкритий GitHub необхідно з'ясувати права на повторне поширення B1+ добірки й замінити її на ліцензовані відкриті дані за потреби.
